KATALON STUDIO

Laboratorio de localizadores

Ejercicios intencionales para practicar desde selectores simples hasta XPath resistentes a cambios.

01

IDs dinámicos

Los campos del formulario reciben un ID distinto cada vez que se abre. Localízalos por relación, texto o atributos semánticos.

//label[contains(.,'Titular')]/following::input[1]
02

Controles sin ID

Los menús de acciones y varios botones no tienen ID ni name. Construye selectores relativos a la fila.

//tr[.//td[contains(.,'POL-')]]//button
03

DOM regenerado

Filtrar, editar o cambiar de sección vuelve a dibujar las filas. Usa esperas explícitas antes de validar.

waitForElementVisible(...)
04

Datos variables

Los folios se generan en el servidor. Valida patrones y relaciones, no valores fijos.

matches('POL-\\d{4}-\\d{3}')
RUTA SUGERIDA

Prácticas de automatización

  1. Alta positiva: registrar una póliza y validar la fila y factura creadas.
  2. Alta negativa: provocar validaciones de correo, prima y fechas.
  3. Modificación: cambiar titular y prima; comprobar propagación a facturas.
  4. Baja lógica: dar de baja una póliza y verificar la factura cancelada.
  5. Reactivación: restaurar una póliza desde el mismo menú contextual.
  6. Eliminación: confirmar la eliminación definitiva y sus datos relacionados.
  7. Data-driven: repetir altas con un CSV y validar cada nueva fila.
